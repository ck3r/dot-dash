What is Morse code?

Morse code sends text as short and long signals: dots and dashes, said dit and dah. Each letter, number and symbol has its own run of them: A is .-, B is -.... The signal can be a tone, a light, a tap or a mark on paper. The one in use today is International Morse code, kept by the ITU; the chart has all of it.

How long is a dot, a dash and the gaps between them?

Everything is counted in units, and a dot is one unit. A dash is three. The gap between the marks inside a letter is one unit, the gap between letters is three, and the gap between words is seven. So the length of a gap, not a different sound, is what tells letters and words apart.

How is Morse code speed measured?

In words per minute, with the word PARIS as the measure: with its gaps it is 50 units long. So a unit lasts 1200 ÷ wpm milliseconds: at 20 words per minute a dot is 60 ms and a dash 180 ms. Learners often hear letters at full speed with longer gaps between them (Farnsworth timing).

How do you say Morse code aloud?

A dash is dah. A dot is di inside a letter and dit at its end. So K, -.-, is dah-di-dah, and S, ..., is di-di-dit. Said this way, a letter has a rhythm you can learn by ear.

What is SOS in Morse code?

SOS is ...---...: three dots, three dashes, three dots, sent as one run with no gap between the letters. It is the distress signal. It isn't short for anything: it was chosen because it is easy to send and hard to mistake.

What is a prosign?

A prosign is two or three letters run together, with no gap between them, that says something about the exchange itself: <AR> ends a message, <SK> ends a contact, <BT> is a pause. They are written in brackets or with a bar over the letters. The prosigns are listed with what each means.

What are Q codes?

Q codes are three letters, starting with Q, that stand for a whole sentence: QTH is "my location is …", QSL is "I confirm receipt". Sent with a question mark, the same code asks: QTH? is "what is your location?". Unlike a prosign, the letters are sent apart. The Q codes are listed with both readings.

What do CQ, 73 and DE mean?

They are abbreviations operators send to save time. CQ calls any station, DE means "from" or "this is", and 73 is "best regards". The abbreviations are listed with what each means.

What are cut numbers?

Cut numbers are digits sent as shorter letters, to save time where only numbers are expected, as in a contest report. N stands for 9 and T for 0, so the perfect signal report 599 is sent 5NN. A stands for 1; the others are rarer.

Does Morse code have capital letters?

No. Morse has one code for each letter, so there is no upper or lower case. By habit it is written in capitals.

What is the Morse tree?

The Morse tree lays every character out by its marks: from the start, a dot goes one way and a dash the other, so each character sits at the end of its own path. E and T are one step down; the rarer letters are deeper, which is why the commonest letters are the quickest to send. The reference draws it, and walks down it as you key.

How do I translate text to Morse code, or Morse to text?

Type in the station: the text shows as Morse as you write, and plays as sound. Keyed or typed as dots and dashes, it reads back as text. A message can be shared as a link, saved as sound or as a picture.

How do you learn Morse code?

By ear, not by sight: learn each letter as a sound at full speed, a few letters at a time, adding one when the last are sure (the Koch method). Counting dots and dashes from a chart is a habit that has to be unlearned later. Sending helps the hearing: Key hero is a game for the sending hand.
